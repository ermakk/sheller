# Начало работы

Sheller — графический SSH/Mosh/Telnet-клиент для Windows. Эта страница поможет установить приложение и открыть первое подключение.

## Требования

| Компонент | Требование |
|-----------|------------|
| ОС | Windows 10/11 x64 |
| Удалённый сервер | SSH-сервер (`sshd`); для Mosh — `mosh-server` |
| Для сборки из исходников | Node.js 20+, npm |
| Сеть для Mosh | UDP-порты 60000–61000 на сервере |
| SSH-агент (опционально) | Windows OpenSSH Agent или `SSH_AUTH_SOCK` |

## Установка

### Готовый установщик

1. Скачайте последний установщик со страницы [Releases](https://github.com/ermakk/sheller/releases).
2. Запустите NSIS-установщик и выберите каталог установки.
3. После установки запустите Sheller с рабочего стола или из меню «Пуск».

Приложение проверяет обновления через GitHub Releases. Автообновление работает только в установленной (упакованной) версии.

### Из исходников

```powershell
npm install
npm run dev
```

Для проверки типов и production-сборки:

```powershell
npm run typecheck
npm run build
```

## Первое подключение

1. Нажмите кнопку создания подключения на боковой панели.
2. Заполните профиль:
   - **Название** — произвольное имя;
   - **Протокол** — `SSH`, `Mosh` или `Telnet`;
   - **Хост** и **порт** — адрес сервера (по умолчанию 22);
   - **Пользователь** — имя учётной записи;
   - **Аутентификация** — пароль, приватный ключ или SSH-агент.
3. Сохраните профиль и подключитесь двойным щелчком.
4. При первом подключении подтвердите отпечаток host key.
5. Если выбран запрос пароля, введите его во время подключения — пароль не сохраняется на диск.

После подключения открывается вкладка терминала. Для SSH/Mosh-сессий доступны SFTP, туннели, Cron и мониторинг.

## Mosh

Mosh требует `mosh-server` на удалённом сервере и открытый UDP-диапазон:

```bash
sudo apt install mosh
sudo ufw allow 60000:61000/udp
```

`mosh-client` уже входит в установщик Sheller. Если используется собственная сборка, WSL или MSYS2, укажите путь к клиенту в профиле. Подробности — в разделе [Подключения](connections.md).

## Проверка работы

- В терминале отображается приглашение удалённой оболочки.
- Вкладка SFTP показывает содержимое домашнего каталога.
- На панели мониторинга появляются графики CPU, RAM, диска и температуры (для Linux-серверов).
