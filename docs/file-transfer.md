# Передача файлов

В SSH- и Mosh-сессиях доступны два независимых способа работы с файлами: встроенный SFTP-менеджер и ZMODEM прямо в терминале.

## SFTP

SFTP-панель открывается для активной SSH/Mosh-сессии и работает поверх того же соединения.

### Операции

| Действие | Описание |
|----------|----------|
| Навигация | Переход по удалённым каталогам, обновление списка |
| Загрузка на сервер | Файл или каталог через диалог выбора |
| Скачивание | Файл или каталог в локальный каталог |
| Drag & drop | Перетаскивание файлов из проводника Windows |
| Создание каталога | Новая папка в текущем удалённом каталоге |
| Переименование | Изменение имени файла или каталога |
| Удаление | Удаление файла или каталога |
| Отмена | Прерывание активной передачи |

Каталоги обрабатываются рекурсивно: при загрузке и скачивании сохраняется структура вложенных папок.

### Очередь и прогресс

- Одновременно выполняется не более двух файловых передач.
- Для каждой передачи показываются имя файла, направление, прогресс и ошибка.
- Передачу можно отменить; уже записанные данные остаются на диске.
- При разрыве соединения незавершённые передачи завершаются ошибкой.

### Ограничения

- SFTP недоступен для Telnet.
- Права определяются удалённым пользователем и настройками `sshd`/SFTP-подсистемы.

## ZMODEM

ZMODEM работает в интерактивном терминале и не требует открытия SFTP-панели.

1. На сервере должны быть установлены `sz` и `rz` (пакет `lrzsz`).
2. Для скачивания запустите `sz файл` — Sheller автоматически предложит выбрать локальный путь.
3. Для загрузки запустите `rz` и выберите файл в диалоге.
4. Прогресс и ошибки отображаются в терминале.

ZMODEM передаёт данные через тот же PTY-поток, что и терминал, поэтому не используйте его одновременно с интенсивным выводом команд.

## Выбор локального пути

При скачивании Sheller открывает системный диалог выбора каталога. При загрузке можно выбрать отдельные файлы или каталог. Пути отображаются в списке передач; содержимое файлов в интерфейсе не показывается.
