# Безопасность

Sheller — локальный десктопный клиент: он не предоставляет сетевой сервис и не хранит данные в облаке. Основные риски связаны с секретами, host key и содержимым удалённого сервера.

## Модель доверия

| Компонент | Доверие |
|-----------|---------|
| Main-процесс | Доверенный: сеть, файлы, секреты |
| Preload | Доверенный мост с фиксированным API |
| Renderer | Изолированный UI без Node.js |
| Удалённый сервер | Недоверенный до проверки host key |
| Файлы профилей | Локальные данные пользователя |

## Хранение секретов

- Пароли, парольные фразы и пароли прокси шифруются Electron `safeStorage` (на Windows — DPAPI).
- Сохранённые секреты не записываются в открытом виде и не передаются в renderer.
- Если `safeStorage` недоступен, приложение использует base64 и предупреждает об этом. Такой режим не обеспечивает криптографическую защиту.
- При экспорте профилей секреты исключаются.
- Приватные ключи не копируются: профиль хранит только путь к файлу.

Рекомендуется защищать учётную запись Windows паролем и не хранить ключи в общедоступных каталогах.

## Изоляция renderer

Окна создаются со следующими параметрами:

```
contextIsolation: true
nodeIntegration: false
sandbox: true
```

В production добавляется CSP:

```
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';
img-src 'self' data:; font-src 'self' data:; connect-src 'self'
```

Это запрещает загрузку внешних скриптов и сетевые запросы из renderer. Внешние ссылки открываются только для `http:`, `https:` и `mailto:` через системный браузер; новые окна Electron блокируются.

## Host key

- При первом подключении используется модель TOFU: отпечаток показывается и сохраняется после подтверждения.
- При несовпадении отображается предыдущий отпечаток.
- Проверяйте изменения через независимый канал (консоль сервера, администратор).
- Отпечатки jump-хостов хранятся отдельно в их профилях.

## Telnet

Telnet передаёт данные и пароли открытым текстом. Используйте его только в доверенной изолированной сети. Для всех остальных сценариев выбирайте SSH или Mosh.

## Обновления

- Обновления загружаются через `electron-updater` из GitHub Releases.
- Проверка и установка выполняются только в упакованной версии.
- Не отключайте проверку подписи/источника обновлений.

## Рекомендации

1. Используйте ключи или SSH-агент вместо сохранённых паролей.
2. Оставляйте `askPassword` включённым на общих машинах.
3. Проверяйте host key при первом подключении и при его изменении.
4. Не экспортируйте профили в недоверенные места и помните, что пути к ключам в экспорте остаются.
5. Ограничивайте права файлов ключей на стороне клиента и сервера.
6. Не запускайте Sheller под учётной записью с избыточными правами.
