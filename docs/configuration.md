# Конфигурация

Sheller не использует базу данных: профили и сниппеты хранятся в JSON в каталоге `userData` Electron. Секреты шифруются средствами ОС.

## Расположение данных

Обычно каталог находится здесь:

```
%APPDATA%\sheller\
├── profiles.json
└── snippets.json
```

Точный путь зависит от имени приложения Electron. Файлы записываются атомарно (временный файл + переименование), поэтому не редактируйте их вручную при запущенном Sheller.

## Профиль подключения

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `name` | — | Имя профиля |
| `group` | пусто | Группа в боковой панели |
| `protocol` | `ssh` | `ssh`, `mosh` или `telnet` |
| `host` | — | Адрес сервера |
| `port` | 22 | Порт (для Telnet обычно 23) |
| `username` | — | Имя пользователя |
| `authMethod` | `password` | `password`, `key` или `agent` |
| `privateKeyPath` | — | Путь к приватному ключу |
| `jumpProfileId` | — | ID промежуточного профиля |
| `tunnels` | `[]` | Список туннелей |
| `askPassword` | `false` | Запрашивать пароль при каждом подключении |
| `keepaliveInterval` | 15000 | Интервал keepalive SSH, мс |
| `proxyType` | `none` | `none`, `socks5` или `http` |
| `proxyHost`, `proxyPort` | — | Адрес прокси |
| `proxyUsername`, `proxyPassword` | — | Аутентификация прокси |
| `bindAddress` | — | Локальный адрес исходящего соединения |
| `hostKey` | — | Сохранённый отпечаток host key |
| `moshClientPath` | — | Свой `mosh-client`, WSL или MSYS2 |
| `hasPassword`, `hasPassphrase` | `false` | Признаки сохранённых секретов |

Служебные поля `id`, `createdAt`, `updatedAt`, `lastUsedAt` управляются приложением.

## Секреты

- Пароль, парольная фраза ключа и пароль прокси шифруются через Electron `safeStorage`.
- В `profiles.json` хранится зашифрованное значение и схема (`safe`).
- Если шифрование ОС недоступно, используется `plain` (base64) и выводится предупреждение в консоль main-процесса.
- Renderer никогда не получает сохранённые секреты — только флаги наличия.
- Пароль в режиме «запрашивать при подключении» на диск не записывается.

Подробнее — в [Security](security.md).

## Импорт и экспорт

- **Экспорт** создаёт JSON с версией `1` и профилями без паролей, парольных фраз и паролей прокси.
- **Импорт** добавляет профили к существующим, генерирует новые `id` и переназначает ссылки jump-хостов.
- Если jump-хост из файла не найден и отсутствует в текущих профилях, импорт завершается ошибкой.
- Циклические jump-цепочки отклоняются.

## Mosh-клиент

Порядок поиска:

1. `moshClientPath` из профиля.
2. Встроенный клиент в ресурсах установленной версии.
3. `PATH`, `C:\Program Files\Mosh`, MSYS2, Cygwin.
4. WSL с установленным `mosh-client`.

Пустое значение означает автоматический выбор.

## Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `SSH_AUTH_SOCK` | Путь к сокету SSH-агента; на Windows по умолчанию используется `\\.\pipe\openssh-ssh-agent` |

Других переменных для работы приложения не требуется. Токены GitHub в самом Sheller не используются: обновления скачиваются из публичных Releases.

## Обновления

- Проверка выполняется через GitHub Releases (`ermakk/sheller`).
- Автообновление доступно только в упакованной версии.
- Настройки публикации заданы в `package.json` (`build.publish`).
