# Туннели

Туннели пробрасывают TCP-порты через активное SSH/Mosh-соединение. Настройки хранятся в профиле и могут запускаться автоматически вместе с сессией.

## Типы туннелей

| Тип | Аналог SSH | Что делает |
|-----|------------|------------|
| Локальный | `ssh -L` | Открывает порт на локальной машине и направляет трафик на хост из сети сервера |
| Удалённый | `ssh -R` | Открывает порт на удалённой машине и направляет трафик на локальный или доступный ей хост |
| Динамический (SOCKS5) | `ssh -D` | Поднимает локальный SOCKS5-прокси через сервер |

## Поля конфигурации

| Поле | Обязательно | Описание |
|------|-------------|----------|
| Название | Да | Имя туннеля в интерфейсе |
| Тип | Да | `local`, `remote` или `dynamic` |
| Bind host | Да | Адрес привязки (обычно `127.0.0.1` или `0.0.0.0`) |
| Bind port | Да | Порт привязки; `0` выбирает свободный порт (кроме remote) |
| Dest host | Для local/remote | Целевой хост |
| Dest port | Для local/remote | Целевой порт |
| Auto start | Нет | Запускать туннель при подключении |

Для динамического туннеля `destHost` и `destPort` не используются. Если выбран порт `0`, фактический порт отображается в панели туннелей после запуска.

## Примеры

### Доступ к базе данных за jump-хостом

```
Тип: local
Bind host: 127.0.0.1
Bind port: 5432
Dest host: db.internal
Dest port: 5432
```

После запуска подключитесь к `127.0.0.1:5432` — трафик пойдёт через SSH-сервер.

### Показать локальный dev-сервер коллеге

```
Тип: remote
Bind host: 127.0.0.1
Bind port: 8080
Dest host: 127.0.0.1
Dest port: 3000
```

Сервер будет принимать соединения на своём `127.0.0.1:8080` и передавать их на ваш локальный порт 3000.

### SOCKS5-прокси

```
Тип: dynamic
Bind host: 127.0.0.1
Bind port: 1080
```

Укажите `socks5://127.0.0.1:1080` в браузере или другом клиенте.

## Управление

- Туннели запускаются и останавливаются на панели сессии.
- Статусы: `stopped`, `starting`, `running`, `error`.
- При ошибке отображается сообщение сервера или локальной ОС.
- Туннели существуют, пока жива сессия; при отключении останавливаются.
- Настройки туннелей сохраняются в профиле и не требуют повторного ввода.

## Ограничения

- Telnet не поддерживает туннели.
- Удалённый туннель зависит от `AllowTcpForwarding` и прав пользователя на сервере.
- Занятый локальный порт приводит к ошибке `EADDRINUSE`; выберите другой порт или `0`.
- Проброс привилегированных портов (<1024) может требовать прав администратора.
